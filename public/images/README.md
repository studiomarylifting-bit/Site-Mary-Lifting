# Imagens do site

Coloque aqui as fotos reais do Studio (resultados, ambiente) e registre-as em
`src/features/catalog/media.ts`. Use apenas imagens cujos direitos pertencem ao Studio e,
para fotos de clientes, somente com a autorização de imagem registrada na ficha.

Sugestão de organização:

- `cilios/<slug-do-servico>.jpg`
- `sobrancelhas/<slug-do-servico>.jpg`
- `depilacao/<slug-do-servico>.jpg`
- `labios/<slug-do-servico>.jpg`
- `studio/`

Proporção recomendada: 4:5, mínimo 1200px de largura. Next.js gera AVIF/WebP automaticamente.
